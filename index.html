📚 AVL Tree Theory

Simple explanations for your Data Structures lab.

🌳

What is an AVL Tree?

An AVL tree is a self-balancing Binary Search Tree. After every insertion or deletion, the tree checks its balance factor and performs rotations whenever necessary.

⚖️

Balance Factor

Balance Factor is calculated as the height of the left subtree minus the height of the right subtree. A valid AVL node has a balance factor of -1, 0 or +1.

↩️

LL Rotation

LL imbalance occurs when a node becomes heavy on its left-left side. It is fixed using a single right rotation.

↪️

RR Rotation

RR imbalance occurs when a node becomes heavy on its right-right side. It is fixed using a single left rotation.

🔄

LR Rotation

LR imbalance occurs when the tree is left-heavy but the insertion happened inside the right subtree of the left child. It requires two rotations.

🔁

RL Rotation

RL imbalance occurs when the tree is right-heavy but the insertion happened inside the left subtree of the right child. It requires two rotations.

⏱️ Time Complexity

AVL maintains logarithmic height.

SEARCH

O(log n)

INSERT

O(log n)

DELETE

O(log n)

ROTATION

O(1)
